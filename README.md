# 🌦️ Offline Weather App

A simple and beginner-friendly weather dashboard built using HTML, CSS, and JavaScript.  
This version works completely offline without any API or internet dependency.

---

## 🚀 Features

- Search weather by city name
- Preloaded weather data for major cities
- Random weather generation for unknown cities
- Clean and responsive UI
- Fully offline working project (no API key needed)
- Beginner-friendly JavaScript logic

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## 📁 Project Structure

weather-offline/
│
├── index.html
├── style.css
└── script.js

---

## ▶️ How to Run

1. Download or clone this project
2. Open the folder
3. Double click on `index.html`
4. The app will run in your browser instantly
